# 🧮 Python Calculator

A beginner-friendly command-line calculator built using Python. This project performs basic arithmetic operations and includes input validation and error handling.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- ❌ Invalid input handling
- 🛡️ Division-by-zero protection
- 🔄 Continuous calculations
- 🚪 Exit option

## 🛠️ Technologies Used

- Python
- Built-in Python functions
- Conditional statements
- Loops
- Exception handling

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python calculator.py
